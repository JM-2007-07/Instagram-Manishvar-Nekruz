# 0013. Реальное время: Socket.IO в NestJS

- Статус: Принято (проверка подключения — Phase 0)
- Дата: 2026-10-21

## Контекст

Паритет с Instagram (ADR 0011) требует событий без перезагрузки: новые сообщения, «печатает…», «прочитано», «в сети»,
уведомления и значки, сигналы звонков. Опрос раз в несколько секунд для этого недостаточен.

## Решение

1. **Socket.IO-шлюз** в NestJS (`@nestjs/websockets` + `@nestjs/platform-socket.io`), модуль `realtime`.
2. **Аутентификация** при подключении — та же HttpOnly-cookie сессии; проверка `Origin` = `WEB_ORIGIN`; без сессии — отказ.
3. **Комнаты:** `user:{userId}` (личные события), `chat:{chatId}` (участники чата), `call:{callId}`.
4. **REST остаётся источником истины:** изменения делаются через REST; сервис после успешной транзакции публикует
   событие. Через сокет отправляются только эфемерные сигналы (печатает, сигналы WebRTC).
5. **Адрес:** браузер не может открыть WebSocket через `rewrites` Next.js надёжно, поэтому для сокета есть один
   публичный адрес `NEXT_PUBLIC_REALTIME_URL`: в разработке `http://localhost:4000` (cookie `localhost` отправляется
   на любой порт), в продакшене — тот же origin, путь `/socket.io/` направляет обратный прокси (Q24).
6. **Один экземпляр backend** — без Redis. Redis-адаптер Socket.IO добавляется вместе с масштабированием (новый ADR).
7. На frontend — один модуль `lib/realtime.ts`; события обновляют кэш RTK Query (`updateQueryData`) или сбрасывают теги.
   Каталог событий — [api/REALTIME.md](../api/REALTIME.md).

## Рассмотренные альтернативы

- **Polling RTK Query** — нет «печатает», «в сети», мгновенных звонков; лишняя нагрузка.
- **Server-Sent Events** — только сервер → клиент; звонкам и «печатает» нужен двусторонний канал.
- **Чистый `ws`** — пришлось бы писать переподключение, комнаты и подтверждения вручную.

## Последствия

- Исключение из правила «нет `NEXT_PUBLIC_*` адресов API» — только `NEXT_PUBLIC_REALTIME_URL` для сокета.
- В Phase 0 проверить: подключение с cookie в dev, отказ при чужом `Origin`, переподключение после перезапуска API.
