## Решения и почему
- Компоненты A (`UserAvatar`, `SaveButton`, `FollowButton`) ещё не в `main`: экраны B импортируют их из одного файла
  `components/temp/student-a.tsx`; после слияния A файл заменяется ре-экспортами — меняется одно место.
- «Создать» открывается маршрутом `/create/` с перехватом в `@modal`: в `nav-items.ts` изменён только `href` у `CREATE`,
  `sidebar.tsx` и `mobile-nav.tsx` не тронуты (их точечно правит A).
- `GET /me` — один хук `useGetCurrentUserQuery` из `features/posts/api.ts` (агенты завели по своему — объединено).
- «✕» диалога — внутри `Dialog.Content` (radix иначе прячет его от экранного диктора).
- **По ревью (reviewer, 3 🔴 исправлены):** видео ждёт `READY` перед `POST /posts` / `POST /stories`
  (`waitForMediaReady` опрашивает `GET /media/{id}/status`, «Повторить» не грузит файл заново); все ленты с курсором —
  `build.infiniteQuery` (раньше `merge` дублировал посты после инвалидации `Feed`); слот `@modal` получил `[...catchAll]`
  и `page.tsx`, чтобы окно поста закрывалось при переходе по ссылке. «Подписаться» в окне поста и Reels скрыто до
  компонента A (статуса подписки в `Post.author` нет). Токены `--overlay`, `--media-backdrop` внесены в DESIGN_SYSTEM.
- `testTimeout` 20 с: под полной параллельной нагрузкой тесты окон не укладывались в 5 с (по одному проходят).
