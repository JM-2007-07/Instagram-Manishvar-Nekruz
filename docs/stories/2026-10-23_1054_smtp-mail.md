## Запрос
При регистрации сайт пишет «мы отправили код», но письмо не приходит, и войти нельзя.

## Что сделано
- Причина: `MAIL_DRIVER=log` — письмо только печатается в журнал API, SMTP не был реализован. Кроме того, процесс
  API упал после перезапуска (порт 4000 был занят старым процессом) — перезапущен.
- По выбору Студента A реализован `MAIL_DRIVER=smtp` на **nodemailer** (новая зависимость `apps/api`, одобрена
  пользователем): `SMTP_HOST`, `SMTP_PORT` (465 — TLS, 587 — STARTTLS), `SMTP_USER`, `SMTP_PASSWORD`, `MAIL_FROM`.
  При `smtp` без хоста и порта API не запускается с понятной ошибкой. В журнал пишется только «Mail sent to …»,
  без текста письма (в нём код).
- `.env.example` — подсказка для Gmail; ONBOARDING §7 — что делать, если код не приходит; REQUIREMENTS Q23 и
  API_CONTRACT (P22) обновлены.

## Решения и почему
- Режим `log` остаётся по умолчанию: разработка и тесты не требуют почтового ящика.
- Пароль SMTP — только в `apps/api/.env` пользователя; агент его не видит и не записывает.
