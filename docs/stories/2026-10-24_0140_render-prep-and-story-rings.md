## Запрос
1. Подготовить проект к деплою на render.com (выбран бесплатный план; одобрено: API пересылает страницы).
2. Историю посмотрел в ленте историй, а на аватарах в ленте и в рекомендациях кольцо как у непросмотренной;
   просмотр из любого места должен отмечать историю, и открывать её можно из любого места.
3. После первой истории пропадает кнопка добавления — нужно уметь добавлять несколько.

## Что сделано
- **Render (ADR 0020):** `render.yaml` — бесплатная PostgreSQL и два сервиса; публичный адрес — `instagram-api`:
  он отвечает на `/api/v1` и `/socket.io`, а страницы пересылает в `instagram-web` (`src/web-proxy.ts`,
  `http-proxy-middleware`, переменная `WEB_UPSTREAM_URL`). `TRUST_PROXY` — доверие балансировщику Render для rate
  limit. `proxy.ts` строит редирект на вход от `PUBLIC_ORIGIN`. Миграции — `prisma migrate deploy` при запуске.
  Пошаговая инструкция и ограничения бесплатного плана — `docs/development/DEPLOYMENT.md`; Q24 закрыт.
- **Кольца историй:** общий `StoryAvatar` (stories): кольцо серое, если все истории просмотрены (тот же кэш
  `getUserStories`, что обновляет просмотрщик), клик открывает первую непросмотренную, без историй — профиль.
  Подключён в шапках публикаций и Reels, подписи поста, комментариях, рекомендациях (лента и «Все»), карточке
  «я» справа, строках списков (подписчики, поиск).
- **Несколько историй:** у «Ваша история» в ленте историй «+» остаётся и при уже опубликованной истории — фото
  открывает свои истории, «+» — окно «Новая история» (ограничения числа историй в API нет).

## Проверка
- Локальная копия схемы Render (API 4200 → Next.js 3200, сборки production): гость → `/accounts/login/` на
  публичном адресе, вход, REST и Socket.IO только через `localhost:4200`, сообщение bob пришло alice без перезагрузки
- `npm run lint`, `npm run typecheck` → без ошибок; `npm run test` → web 42 файла, 186 тестов; api 72 теста
  (новый `web-proxy.spec.ts`)
- Chrome без окна (carol): после просмотра историй alice в ленте историй её кольцо стало серым и в шапках
  публикаций; клик по аватару в шапке поста открывает историю
- ⚠️ не проверено: настоящий деплой на Render (нужен вход в аккаунт Render и push в GitHub)

## Решения и почему
- Бесплатные сервисы Render не принимают внутренний трафик, а cookie не переходит между `*.onrender.com` —
  поэтому один публичный адрес через API (альтернативы — в ADR 0020).
