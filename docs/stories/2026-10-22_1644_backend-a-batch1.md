## Запрос
Сдача 2026-10-24, нужен полный паритет с Instagram. Студент A попросил перейти в быстрый режим и сделать всё: процесс упрощён, объём полный.

## Что сделано
- **Direct (T2.A4):** личные и групповые чаты, сообщения (текст, ответ, правка 15 мин, отмена, `clientId`), реакции, «прочитано»,
  запросы на переписку, mute, удаление у себя, администраторы групп, `chat:typing`, события `message:*`/`chat:*`, «поделиться профилем»,
  `ChatsService.sendSystemMessage()` для ответов на истории (B), `countUnreadChats()` → `GET /me/badges`.
- **Уведомления (T2.A2):** модель `Notification`, настоящий `create()` (себя, выключенные типы и блокировки отсекаются, повторы не создаются),
  `remove()` при отмене, группировка за 24 ч, `GET /notifications`, `POST /notifications/read`, `GET /me/badges`, события.
- **Соцвход (T4.A1):** Google и Facebook, Authorization Code + PKCE, привязка по подтверждённому email, завершение регистрации, отвязка.
  Без ключей кнопки скрыты: `providers` → false, `/auth/oauth/{provider}` → 404.
- **Звонки (T4.A2):** `Call`/`CallParticipant`, старт/принять/отклонить/завершить по REST, события `call:*`, сигнализация `call:signal`,
  `GET /calls/ice-servers` (STUN + временный TURN по HMAC).
- **Ограничение, скрытие, близкие друзья, избранное, «скрыть историю от», скрытые слова (T4.A3)** и новые методы `VisibilityService` для B.
- **Деактивация, удаление через 30 дней, 2FA (T4.A4):** TOTP (RFC 6238 на `node:crypto`), секрет в AES-256-GCM, резервные коды, двухшаговый вход.
- Одна миграция `add_chats_notifications_oauth_calls_privacy`.

## Решения и почему
- Быстрый режим: четыре агента пишут параллельно, каждый в своих модулях. Миграцию и e2e делает только оркестратор, иначе общая БД ломает прогоны.
- Ссылки на модели B (`postId`, `commentId`, `storyId`, `mediaId`, `chatId` в звонках) — nullable uuid без relation. FK добавятся, когда B создаст модели.
- Отправка медиа, голосовых, «поделиться постом/историей» → 400 `NOT_IMPLEMENTED` до T1.B1/T1.B4/T2.B1.
- Звонки идут по контракту `calls.md`: управление через REST, по сокету — только `call:signal`.
- `NotificationsService` не импортирует `chats`: счётчик чатов передаётся через `registerUnreadChatsCounter` (без цикла модулей).
