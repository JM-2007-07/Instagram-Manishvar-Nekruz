## Что сделано
- **Обход экранов:** 19 адресов (лента, «Интересное», поиск, люди, Reels, профили, подписчики, публикация, Direct,
  чат, настройки, «Сохранённое», уведомления, история, хэштег, вход, регистрация, сброс пароля) × светлая и тёмная
  тема × 1280 и 375 px — 76 загрузок без ошибок страницы, без ответов 5xx, без предупреждений гидрации и без
  горизонтальной прокрутки (Chrome без окна, Playwright из временной папки).
- **API перезапускался сам:** в режиме `nest start --watch` API несколько раз за 10 минут видел «изменения файлов»
  и перезапускался (~5 с без API: «Что-то пошло не так», обрыв сообщений и звонков). Источник — события файловой
  системы вне кода проекта (антивирус, индексатор или редактор трогают `node_modules`), точно не установлен.
  Для показа добавлен локальный запуск `api-stable` (`npm run build -w api && npm run start -w api`) — без
  перезапусков; сейчас API работает так.
- **Выход:** кэш TanStack Query (поиск аккаунтов) теперь очищается при выходе (`useClearAccountSearch`), как и кэш
  RTK Query — иначе следующий вошедший мог увидеть чужие результаты поиска.
- **Кнопка «Сообщения»** скрыта на странице публикации, в настройках и в историях — там она закрывала поле
  комментария и кнопку «Отправить».
- **Деплой:** `docs/development/DEPLOYMENT.md` — что запускать, схема адресов (один origin, `/socket.io/` на API),
  имена переменных, проверки после запуска. Сам деплой не делали (Q24 открыт, пользователь просил пока не деплоить).
- **Campus Mode:** отложен. В модели нет поля вуза и сущности «сообщество»: нужны новые таблицы, миграция, новые
  endpoint'ы и изменение контракта — по правилам проекта это согласование с обоими студентами; за вечер до экзамена
  риск выше пользы.
- **TanStack Table:** интерфейса админ-панели в `apps/web` нет (есть только endpoint'ы `/admin/*` в API) — не применимо.
