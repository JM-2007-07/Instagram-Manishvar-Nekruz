## Запрос
Список P0/P1 перед экзаменом: просмотр историй и их «просмотренность», окна подписчиков/подписок, правка поста,
голосовые в Direct, «Завершить» и «Свернуть» у звонка, поиск как у Instagram на TanStack Query, закрытие эмодзи,
рекомендации и кнопка «Подписки», счётчики в ленте, значок в меню. Деплой — не делать.

## Что сделано
- **Истории:** просмотр отмечается в кэше автора (`getUserStories`, `getStory`); кольцо в ленте историй гаснет, когда
  у автора не осталось непросмотренных; из ленты историй показ начинается с первой непросмотренной; аватар в шапке
  профиля открывает истории (`StoryAvatarLink`) и показывает серое тонкое кольцо, если всё просмотрено.
  Демо-данные добавляют свежие истории bob и carol (истории живут 24 часа).
- **Подписчики/подписки:** окна из перехваченного маршрута получали имя с маркером `(...)` — маркер убирается.
- **Рекомендации:** после «Подписаться» человек остаётся в списке (`useStableList`), кнопка «Подписки ▾» открывает
  меню «Отменить подписку»; 6 новых демо-пользователей для рекомендаций.
- **Правка поста:** «Редактировать» в меню своего поста — окно «Редактировать информацию» (подпись, скрыть лайки,
  отключить комментарии), `PATCH /posts/{id}`, кэш поста и ленты обновляется без перезагрузки.
- **Лента:** числа лайков и комментариев рядом со значками (у «Поделиться» числа нет — API его не считает).
- **Голосовые:** запись с секундомером, «Отменить» и «Отправить», лимит 60 с, понятные ошибки микрофона; файл
  отправляется только после обработки на сервере (`READY`) — раньше API отклонял сообщение. Видео в Direct — так же.
  В сообщении — свой плеер (▶/❚❚, полоса с перемоткой, время).
- **Звонок:** «Свернуть» — панель в правом нижнем углу (видео собеседника, имя, время, микрофон, развернуть,
  завершить), связь не прерывается; нет доступа к камере — звонок сразу завершается на сервере, а не «висит».
- **Эмодзи в Direct:** панель закрывается после выбора, по Escape и по клику мимо.
- **Поиск:** аккаунты — TanStack Query (`features/search/user-search.ts`, один `QueryClient`), хэштеги и места —
  RTK Query (`/search/hashtags`, `/search/locations`); «Интересное» — поле поиска сверху, при вводе результаты
  вместо сетки. ADR 0019, исключение в AGENTS.md и ESLint.
- **Меню:** знак «Главная» — векторный контур `currentColor` вместо картинки `mark.png`.
- **TanStack Table:** интерфейса админ-панели в `apps/web` нет — применять не к чему.

## Решения и почему
- TanStack Query только для аккаунтов, чтобы не было двух кэшей одних данных; общий `GET /search` поиском больше
  не используется — аккаунты не запрашиваются дважды ([ADR 0019](../decisions/0019-tanstack-query-user-search.md)).
- Серое кольцо в профиле считается на клиенте по `isViewedByMe` историй — контракт не менялся.

## Проверка
- `npm run lint` (web, api) → без ошибок; `npm run typecheck` → без ошибок
- `npm run test` → web 40 файлов, 182 теста; api 69 тестов; `npm run build -w web` → собирается
- В браузере (alice): истории bob/carol — просмотр уходит на сервер по одному разу, переход к следующему автору,
  кольца серые после перезагрузки и в профиле bob; правка подписи сохраняется после перезагрузки (подпись вернул);
  счётчики в ленте; голосовое (загружено через API) проигрывается до конца; видеозвонок без камеры завершается сам;
  поиск на «Интересном» — по одному запросу на аккаунты, хэштеги и места; значок меню векторный.
- ⚠️ не проверено: запись голоса с микрофона и разговор двух людей с камерами (во встроенном браузере нет устройств) —
  нужно проверить на ноутбуке перед экзаменом; свёрнутый звонок проверен только тестом компонента.
