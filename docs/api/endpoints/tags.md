# Эндпоинты: `tags`

> Модуль `tags` · функции F-TAG-*, F-SRC-04 · спецификация [hashtags-and-mentions.md](../../features/hashtags-and-mentions.md).

| Метод и путь | Доступ | Запрос | Ответ | Ошибки | F |
|---|---|---|---|---|---|
| `GET /hashtags/{name}` | User | — | `Hashtag` | 404 | F-SRC-04 |
| `GET /hashtags/{name}/posts` | User | `?tab=TOP\|RECENT&cursor` | `Page<Post>` (только видимые) | 404 | F-SRC-04 |

Разбор текста (используется модулями `posts`, `comments`, `stories`, `users`):

- Хэштег: `#` + буквы/цифры/`_` (Unicode, включая кириллицу), до 100 📝 символов; хранится в нижнем регистре; до 30 📝 в подписи.
- Упоминание: `@` + допустимое имя пользователя; превращается в ссылку только для существующего видимого аккаунта.
- `TOP` — посты за 7 дней по числу лайков и комментариев; `RECENT` — новые сначала (ADR 0011).

Подсказки при вводе `#` и `@` — [search.md](search.md) (`/search/hashtags`, `/search/mentions`).
