# Экраны

> Статус: ✅ структура принята; размеры — из [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md). ✅ — наблюдалось на instagram.com
> 2026-10-21, 📝 — сверить. Маршруты повторяют адреса Instagram. Функции — ID из [FEATURE_CATALOG.md](../product/FEATURE_CATALOG.md).

## 0. Как сверять дизайн

1. Каждый экран реализуется по этому документу и токенам; отступы и размеры — из DESIGN_SYSTEM §4.
2. **Дизайн-сверка** — в каждой UI-задаче и итоговая (T7.2 в [IMPLEMENTATION_PLAN.md](../IMPLEMENTATION_PLAN.md)):
   - открыть экран Instagram и наш экран при одинаковой ширине окна (1150 и 375 px), светлая и тёмная тема;
   - сравнить скриншоты и вычисленные стили (`getComputedStyle`) ключевых элементов;
   - расхождения — исправить или записать в «Отклонения» экрана ниже.
3. Сверку выполняет студент или агент. Агент в браузере пользователя работает **только на чтение**: не ставит
   «Нравится», не подписывается, не открывает переписки и истории (это меняет состояние чужих аккаунтов),
   не меняет настройки. Входит в Instagram сам пользователь.

## 2. Оболочка приложения

- **Десктоп (≥ 768 px):** боковое меню 72 px слева, раскрытие до 238 px при наведении ✅; контент по центру.
  Пункты: Главная, Reels, Сообщения, Поисковый запрос, Уведомления, Создать, Профиль, Ещё ✅.
- **Мобильный (< 768 px) 📝:** верхняя панель (логотип, «Уведомления», «Сообщения»), нижняя панель
  (Главная, Интересное, Reels, Создать, Профиль).
- Значки: счётчик сообщений (красный, «9+» ✅), точка на «Уведомления» ✅.
- Гость: верхняя панель 60 px с «Войти» / «Зарегистрироваться» ✅; модальное окно с предложением регистрации
  при попытке посмотреть контент ✅.

## 3. Экраны

Для каждого экрана: раскладка, элементы, состояния (загрузка / пусто / ошибка), отклонения от Instagram.

### 3.1 Вход ✅
Колонка ~432 px 📝 по центру: заголовок «Войти в ‹APP_NAME›», поле «Имя пользователя, номер мобильного телефона или
электронный адрес», «Пароль» (скругление 12 px, рамка 1 px), кнопка «Войти» во всю ширину (неактивна, пока поля
пусты), «Забыли пароль?», разделитель, «Войти через Facebook» (вторичная кнопка с иконкой), **«Войти через Google»**
(дополнение), «Создать новый аккаунт» (кнопка с рамкой), знак бренда внизу; подвал со ссылками и выбором языка ✅.
Ошибка — текст под кнопкой цветом `--destructive`.

### 3.2 Регистрация
Поля: email, пароль, дата рождения (три списка), полное имя, имя пользователя (проверка «на лету», подсказки),
кнопка «Зарегистрироваться» → экран «Введите код подтверждения» (6 цифр, «Отправить код ещё раз»).

### 3.3 Главная
Колонка 630 px ✅: лента историй (74/89 px, стрелки) → посты (карточка 470 px). В конце — «Вы всё посмотрели» →
«Предыдущие публикации». Плавающая кнопка «Сообщения» ✅. Правая колонка (≥ 1264 px 📝): свой аккаунт,
«Рекомендации для вас», «Все», подвал.
Состояния: skeleton карточек; пусто — «Добро пожаловать» + рекомендации аккаунтов.

### 3.4 Карточка поста ✅
Шапка (аватар с кольцом истории, имя, галочка, «• время», место, «…») → медиа 468 px (карусель со стрелками и
точками; видео со звуком по клику) → кнопки → «N отметок "Нравится"» → подпись с «ещё» → «Посмотреть все
комментарии (N)» → поле комментария с эмодзи.

### 3.5 Публикация (модальное окно / страница)
Слева медиа (на высоту окна), справа 335–500 px 📝: шапка автора, подпись как первый комментарий, комментарии с
ответами, кнопки, число лайков, дата, поле комментария. Стрелки «‹ ›» к соседним публикациям профиля.

### 3.6 Создание публикации ✅ (частично)
Шаги в одном окне: 1) выбор файлов («Перетащите сюда фото и видео», «Выбрать на компьютере» ✅) → 2) обрезка
(формат, масштаб, карусель) → 3) редактирование (фильтры/настройки) → 4) подпись, место, отметки, alt-текст,
соавторы, расширенные настройки → «Поделиться» → прогресс → «Ваша публикация опубликована». Кнопки «Назад» / «Далее»
в шапке окна. Закрытие с несохранёнными изменениями — «Удалить публикацию?».

### 3.7 Reels
Видео 9:16 по центру на высоту экрана, справа столбец действий; подпись и звук внизу на видео; прокрутка по одному.

### 3.8 Интересное ✅
Строка поиска сверху; при вводе — выпадающий список результатов (аккаунты, хэштеги, места) и «Недавнее» с
«Очистить все»; сетка 3×(3:4).

### 3.9 Профиль ✅
Шапка (аватар 150, имя 20 px, кнопки, счётчики, имя, bio, ссылки, «Подписаны: …»), актуальное (77/92), вкладки
(44 px), сетка 3:4. Закрытый — замок и текст. Чужой: «Подписаться» (`--button-primary`), «Сообщение»
(`--button-secondary`), «…». Свой: «Редактировать профиль», «Посмотреть архив».

### 3.10 Просмотр истории
Тёмный фон, история 9:16 по центру, соседние истории уменьшены по бокам 📝; сверху полоски прогресса, аватар, имя,
время, пауза, звук, «…»; снизу поле ответа, сердце, «Поделиться». Для автора — «Просмотры: N» со списком.

### 3.11 Direct
Слева список (≈ 397 px 📝): аватар, имя, «последнее сообщение · время», точка; сверху своё имя, «новое сообщение»,
заметки (P2), вкладки «Основное / Запросы». Справа переписка: шапка (аватар, имя, «В сети», звонок, видео, «i»),
пузыри (входящие `--bubble-incoming`, исходящие `--bubble-outgoing`), реакции, ответы, «Просмотрено»; поле ввода
(эмодзи, микрофон, фото, сердце, «Отправить»). Пусто — «Ваши сообщения» + «Отправить сообщение».

### 3.12 Звонок
Окно поверх: видео собеседника на весь экран, своё — в углу; кнопки микрофон / камера / завершить (`--destructive`).
Входящий — карточка с аватаром, «Принять» (`--success`) / «Отклонить».

### 3.13 Уведомления
Панель/страница: блок «Запросы на подписку» сверху, группы по времени, строки «аватар — текст — время — миниатюра
или кнопка "Подписаться"».

### 3.14 Настройки
Слева список разделов, справа содержимое; переключатели (`--ig-toggle-*` ✅), списки (заблокированные, близкие друзья).
