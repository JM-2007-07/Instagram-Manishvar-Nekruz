# Посты, лента и reels

## Назначение
Публикация постов с изображениями (и видео для reels), просмотр, удаление, лента подписок,
общая лента «Интересное», посты пользователя, reels. Взаимодействия (лайки, комментарии и т.д.) —
в [post-interactions.md](post-interactions.md).

## Пользовательские сценарии
1. **Создание:** выбрать 1–10 изображений (превью, порядок = порядок выбора) → необязательные заголовок и текст →
   «Опубликовать» → пост появляется в профиле и ленте подписчиков.
2. **Reel (Q10):** выбрать одно видео → текст → «Опубликовать» → пост с `isReel = true`.
3. **Лента (главная):** посты моих подписок и мои, новые сначала, бесконечная прокрутка.
4. **«Интересное»:** все посты, новые сначала; поле поиска по тексту (Q28).
5. **Reels:** вертикальная лента видео, по одному на экран.
6. **Пост:** отдельная страница `/p/{postId}`: медиа (карусель), автор, текст, дата, счётчики, комментарии.
7. **Удаление:** автор → меню «…» → «Удалить» → подтверждение → пост исчезает отовсюду.

## API
`GET /feed`, `GET /posts`, `GET /users/{userId}/posts`, `GET /reels`, `GET /posts/{postId}`, `POST /posts`,
`DELETE /posts/{postId}` — [API_CONTRACT.md §2.4](../api/API_CONTRACT.md#24-posts-reels-лента-и-взаимодействия-posts-module).

## Данные
`Post`, `PostMedia`, `MediaFile`; `Post.locationId` — только по ответу на Q20.

## Права доступа
- Читать — любой вошедший (Q22).
- Создавать — любой вошедший, автор = текущий пользователь.
- Удалять — только автор (`403` для остальных).

## Валидация 📝
| Поле | Правило |
|---|---|
| `title` | ≤ 100 символов, необязателен |
| `content` | ≤ 2200 символов, необязателен |
| `files` (пост) | 1–10 изображений JPEG/PNG/WebP, каждое ≤ 10 МБ |
| `files` (reel) | ровно 1 видео MP4 ≤ 100 МБ (Q10); смешивать фото и видео нельзя |
| `search` | ≤ 100 символов |

Загруженный набор файлов определяет тип поста: одно видео → reel, изображения → обычный пост.

## Ошибки и пустые состояния
- Лента пуста (нет подписок) → «Подпишитесь на кого-нибудь» + ссылка на «Интересное».
- Пост не найден/удалён → `404` → страница «Публикация недоступна».
- Файл не прошёл проверку → `413`/`415` → сообщение у конкретного файла; ничего не создаётся.
- Ошибка посреди загрузки → пост не создаётся частично (транзакция; уже сохранённые файлы удаляются).

## Зависимости
auth, storage/media; лента — follows. От posts зависят: post-interactions, stories (сторис из поста), избранное.

## Критерии приёмки
- [ ] Пост создаётся атомарно: при ошибке любого файла нет ни записи, ни файлов.
- [ ] Порядок медиа сохраняется.
- [ ] `GET /feed` возвращает только посты подписок и свои, по убыванию даты, постранично.
- [ ] `GET /reels` возвращает только reels.
- [ ] Удаление поста удаляет медиафайлы, лайки, комментарии, просмотры, избранное (и сторис — Q12).
- [ ] Чужой пользователь не может удалить пост (`403`).
- [ ] Медиа доступны по `url` из ответа и только вошедшим пользователям.
- [ ] UI: карусель, бесконечная прокрутка, состояния загрузки/пусто/ошибка; мобильная ширина.
