# Публикации, ленты и reels

> Функции F-PST-*, F-FED-*, F-REL-* · API [endpoints/posts.md](../api/endpoints/posts.md), [media.md](../api/endpoints/media.md) ·
> экраны [SCREENS.md §3.3–3.7](../design/SCREENS.md#33-главная) · размеры [DESIGN_SYSTEM.md §4.2](../design/DESIGN_SYSTEM.md#42-лента-).
> Лайки, комментарии, сохранение — [post-interactions.md](post-interactions.md).

## Назначение
Создание публикаций (карусели фото и видео) и reels, просмотр, редактирование, архив, закрепление, удаление;
главная лента, ленты «Подписки» и «Избранное», «Интересное», Reels, вкладки профиля.

## Пользовательские сценарии
1. **Создание (P0):** «Создать» → окно ✅ → перетащить или «Выбрать на компьютере» (несколько файлов) → обрезка
   (формат 1:1 / 4:5 / 16:9 / оригинал, масштаб; P1) → фильтры и настройки (P2) → подпись (эмодзи, подсказки `@`/`#`),
   место, отметки людей на фото, alt-текст, соавторы (P2), «Расширенные настройки» (скрыть лайки, отключить
   комментарии) → «Поделиться» → прогресс → «Ваша публикация опубликована». Закрыть с изменениями → «Отменить публикацию?».
2. **Reel (P0):** выбрать одно вертикальное видео → обложка (кадр со шкалы или изображение) → подпись → «Поделиться»;
   пока видео обрабатывается — «Reel обрабатывается».
3. **Главная (P0):** лента историй → публикации подписок; в конце свежих — «Вы всё посмотрели» → «Предыдущие публикации».
4. **Карточка поста (P0):** шапка, карусель со стрелками и точками ✅, кнопки ✅, лайки, подпись с «ещё» ✅,
   «Посмотреть все комментарии (N)», поле комментария; двойной клик — лайк с сердцем.
5. **Окно поста (P0):** из сетки/ленты — окно с URL `/p/{shortcode}/` ✅, стрелки к соседним публикациям; прямая ссылка — страница.
6. **Редактирование (P1):** «…» → «Редактировать» → подпись, место, отметки, alt-текст → «Готово».
7. **Архив, закрепление, удаление** — через «…» своего поста; удаление с подтверждением.
8. **Reels (P0):** `/reels/` — вертикальная лента, одно видео на экран, автовоспроизведение без звука, звук по клику,
   действия справа.
9. **Ленты «Подписки» / «Избранное» (P1):** выбор в меню логотипа 📝 — строго по времени.

## Данные
`Post`, `PostMedia`, `PostUserTag`, `PostCollaborator`, `PostLike`, `PostPlay`, `PostMention`, `MediaFile` —
[DATA_MODEL.md «Публикации»](../database/DATA_MODEL.md#публикации-posts).

## Права доступа
Видимость — по правилам приватности (закрытый аккаунт, блокировка, архив). Создание — вошедший; редактирование,
архив, закрепление, удаление — автор; соавтор может выйти из соавторства.

## Валидация 📝
| Поле | Правило |
|---|---|
| медиа | 1–20 на пост; фото/видео вперемешку; лимиты файлов — SECURITY.md; reel — ровно одно видео 9:16 ≤ 3 мин |
| подпись | ≤ 2200 символов, ≤ 30 хэштегов, ≤ 20 упоминаний |
| отметки | ≤ 20 на медиа; только существующие пользователи с `tagsFrom`, разрешающим меня |
| соавторы | ≤ 5 |
| закреплённые | ≤ 3 |

## Ошибки и пустые состояния
- Пустая главная (нет подписок) → «Добро пожаловать» + рекомендации аккаунтов.
- Пост недоступен → «К сожалению, эта страница недоступна» / в окне — «Публикация недоступна».
- Файл не прошёл проверку → ошибка у конкретного файла, остальные остаются.
- Видео не обработалось → «Не удалось обработать видео» + «Повторить».

## Зависимости
auth, media, privacy, tags (разбор подписи), locations, follows (лента), notifications (отметки, упоминания, соавторство).

## Критерии приёмки
- [ ] Карусель до 20 элементов с фото и видео; порядок сохраняется; формат обрезки один на карусель.
- [ ] Пост с видео публикуется после обработки; автор получает `post:published`.
- [ ] Подпись создаёт связи с хэштегами и упоминаниями; упомянутые и отмеченные получают уведомления с учётом настроек.
- [ ] Редактирование меняет подпись/место/отметки/alt и обновляет хэштеги; `editedAt` заполняется.
- [ ] Архивный пост виден только автору; закреплённые — первыми в сетке; четвёртое закрепление → `409`.
- [ ] `GET /feed` — посты подписок (без скрытых), новые сначала, «Избранное» выше, затем элемент `CAUGHT_UP`.
- [ ] `/p/{shortcode}/` открывается окном из сетки и страницей по прямой ссылке.
- [ ] Удаление поста удаляет медиа, комментарии, лайки, сохранения, уведомления.
- [ ] Карточка, окно и сетка совпадают с DESIGN_SYSTEM §4.2–4.3 в обеих темах.
