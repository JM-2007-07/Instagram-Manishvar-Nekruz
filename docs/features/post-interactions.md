# Лайки, комментарии, просмотры, избранное

## Назначение
Реакции на посты. Общие правила механик — [REQUIREMENTS.md §4.3–4.6](../REQUIREMENTS.md#4-требования-к-отдельным-механикам).

## Пользовательские сценарии
1. **Лайк:** сердце под постом (или двойной тап по медиа) → заполняется сразу (оптимистично), счётчик +1; повторный клик снимает.
2. **Комментарий:** поле под постом → «Опубликовать» → комментарий в конце списка; автор комментария (и автор поста — Q13) может удалить.
3. **Просмотр:** засчитывается автоматически при открытии поста или когда пост виден в ленте ≥ 1 с (Q14). Число просмотров поста видно всем (у сторис — только автору).
4. **Избранное:** значок закладки → пост в «Сохранённом» (`/saved`); повторный клик убирает.

## API
`PUT|DELETE /posts/{postId}/like`, `PUT /posts/{postId}/view`, `GET|POST /posts/{postId}/comments`,
`DELETE /comments/{commentId}`, `PUT|DELETE /posts/{postId}/favorite`, `GET /me/favorites` —
[API_CONTRACT.md §2.4](../api/API_CONTRACT.md#24-posts-reels-лента-и-взаимодействия-posts-module).

## Данные
`PostLike`, `PostView`, `PostFavorite` (составные ключи — по одной записи на пользователя и пост), `Comment`.

## Права доступа
| Действие | Кто |
|---|---|
| лайк, просмотр, избранное, комментарий | любой вошедший |
| удалить комментарий | автор комментария; автор поста (Q13) |
| видеть «Сохранённое» | только владелец |
| видеть число просмотров | все (в `Post.viewCount`) 📝 |

## Валидация
- Комментарий: 1–1000 символов после обрезки пробелов.
- Пост должен существовать (`404`).
- Свой просмотр автором не записывается.

## Ошибки и пустые состояния
- Нет комментариев → «Будьте первым, кто оставит комментарий».
- «Сохранённое» пусто → «Сохраняйте публикации, чтобы вернуться к ним».
- Ошибка лайка/избранного → откат оптимистичного состояния + toast.
- Пост удалён, пока открыт → `404` на действие → сообщение «Публикация удалена».

## Зависимости
posts. Избранное отображается в профиле владельца (вкладка) или на `/saved`.

## Критерии приёмки
- [ ] Повторные `PUT` не создают дубликатов; `DELETE` без записи — `204`.
- [ ] `likeCount`, `commentCount`, `viewCount`, `isLikedByMe`, `isFavoritedByMe` соответствуют данным.
- [ ] Просмотр автора своего поста не увеличивает `viewCount`.
- [ ] Чужой комментарий нельзя удалить (кроме автора поста — по Q13) → `403`.
- [ ] `GET /me/favorites` возвращает только свои, недавно добавленные сначала.
- [ ] Лайк и избранное отражаются в UI мгновенно и согласуются с сервером после ответа.
