# Лайки, комментарии, сохранённое, просмотры, «поделиться»

> Функции F-INT-* · API [posts.md](../api/endpoints/posts.md), [comments.md](../api/endpoints/comments.md),
> [collections.md](../api/endpoints/collections.md), «поделиться» — [chats.md](../api/endpoints/chats.md) ·
> правила механик [REQUIREMENTS.md §4.3–4.6](../REQUIREMENTS.md#4-требования-к-отдельным-механикам).

## Назначение
Реакции на публикации: лайки, комментарии с ответами, лайки комментариев, закрепление, редактирование, сохранение в
подборки, просмотры видео, отправка публикации в Direct и в историю.

## Пользовательские сценарии
1. **Нравится (P0):** сердце или двойной клик по медиа (анимация); заполненное красное сердце; число «N отметок
   "Нравится"» — клик открывает список (если автор не скрыл).
2. **Комментарий (P0):** поле «Добавьте комментарий…», эмодзи, «Опубликовать» активна при непустом тексте.
3. **Ответ (P0):** «Ответить» под комментарием → в поле `@имя ` → ответ попадает под родительский; ответы свёрнуты
   «— Посмотреть ответы (N)».
4. **Лайк комментария (P0):** маленькое сердце справа; «N отметок "Нравится"» под комментарием.
5. **«…» у комментария:** свой — «Изменить» (15 мин), «Удалить»; на своём посте — «Закрепить», «Удалить»,
   «Ограничить», «Пожаловаться»; чужой — «Пожаловаться».
6. **Сохранить (P0):** закладка → «Сохранено» с предложением «Сохранить в подборку» (P1) → выбор/создание подборки.
7. **Сохранённое (P0/P1):** вкладка своего профиля: «Все публикации» и подборки (обложка из 4 миниатюр 📝).
8. **Поделиться (P0):** самолёт → окно «Поделиться»: поиск людей и чатов, несколько получателей, сообщение,
   «Отправить»; «Добавить публикацию в историю»; «Копировать ссылку».
9. **Просмотры (P1):** видео и reels засчитывают воспроизведение при старте проигрывания; число на плитке reel.

## Данные
`PostLike`, `PostPlay`, `Comment`, `CommentLike`, `CommentMention`, `SavedPost`, `Collection`, `CollectionItem` —
[DATA_MODEL.md](../database/DATA_MODEL.md#комментарии-comments).

## Права доступа
| Действие | Кто |
|---|---|
| лайк, сохранение, поделиться | любой, кто видит пост |
| комментарий | видящий пост + `commentsFrom` автора + комментарии не отключены |
| изменить комментарий | автор, 15 минут |
| удалить комментарий | автор комментария или поста |
| закрепить, одобрить | автор поста |
| список лайков | все, если автор не скрыл; иначе только автор |
| сохранённое, подборки | только владелец |

## Валидация 📝
Комментарий 1–2200 символов, ≤ 5 упоминаний 📝; ответ — только на комментарий верхнего уровня; закреплённых ≤ 3;
название подборки 1–50.

## Ошибки и пустые состояния
- Нет комментариев → «Комментариев пока нет. Начните переписку.» 📝
- Комментарии отключены → «Комментарии к этой публикации отключены».
- Сохранённое пусто → «Сохраняйте понравившееся» + пояснение.
- Ошибка лайка/сохранения → откат состояния + тост.

## Зависимости
posts, privacy, tags, notifications (`POST_LIKE`, `COMMENT`, `COMMENT_REPLY`, `COMMENT_LIKE`, `MENTION_COMMENT`), chats (поделиться).

## Критерии приёмки
- [ ] Повторные `PUT` не создают дубликатов; снятие лайка удаляет непрочитанное уведомление.
- [ ] Двойной клик ставит лайк (не снимает) и показывает анимацию.
- [ ] Ответ на ответ → `400`; ответы выдаются под родителем по возрастанию времени.
- [ ] Редактирование после 15 минут → `409 EDIT_WINDOW_EXPIRED`; отметка «Изменено».
- [ ] Автор поста удаляет чужой комментарий; чужой пользователь — `403`.
- [ ] Комментарий ограниченного пользователя виден только ему и автору поста до одобрения.
- [ ] Скрытое автором число лайков не отдаётся (`likeCount: null`) никому, кроме автора.
- [ ] Удаление из «Сохранённого» убирает пост из всех подборок.
- [ ] «Поделиться» нескольким получателям создаёт по сообщению `SHARE_POST` в каждом чате.
- [ ] Воспроизведение засчитывается не чаще раза в час на пользователя.
