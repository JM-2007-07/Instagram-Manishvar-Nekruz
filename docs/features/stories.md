# Stories

## Назначение
Временные публикации (24 часа — Q11) из изображения/видео или из существующего поста; просмотры и лайки.

## Пользовательские сценарии
1. **Публикация:** «Создать» → «Сторис» → выбрать изображение (видео — Q10) → «Поделиться».
2. **Сторис из поста:** на своём посте «…» → «Поделиться в сторис» (Q12) → сторис-карточка с превью поста; клик ведёт к посту.
3. **Лента сторис:** круги аватаров вверху главной; непросмотренные — с цветной рамкой и первыми.
4. **Просмотр:** полноэкранный режим, автопереход через ~5 с, переход к следующему автору, закрытие.
   Просмотр отмечается автоматически; можно поставить лайк.
5. **Автор:** видит число просмотров и лайков, список зрителей (с отметкой лайка); может удалить сторис.

## API
`GET /stories/feed`, `GET /users/{userId}/stories`, `GET /stories/{storyId}`, `POST /stories`, `DELETE /stories/{storyId}`,
`PUT /stories/{storyId}/view`, `PUT|DELETE /stories/{storyId}/like`, `GET /stories/{storyId}/viewers` —
[API_CONTRACT.md §2.5](../api/API_CONTRACT.md#25-stories-stories-module).

## Данные
`Story` (ровно одно из `mediaId`/`sharedPostId`, `expiresAt`), `StoryView`, `StoryLike`, `MediaFile`.

## Права доступа
- Активные сторис видит любой вошедший (Q22); лента — только подписки и свои.
- Счётчики и список зрителей — только автор (у остальных `viewCount`/`likeCount` = `null`).
- Удаление — только автор.
- Сторис из поста — только из своего поста (Q12).

## Валидация 📝
- Ровно одно из `file` или `postId` (иначе `400`).
- Изображение JPEG/PNG/WebP ≤ 10 МБ; видео MP4 ≤ 50 МБ (Q10).
- Истёкшая сторис → `404` для всех операций.

## Ошибки и пустые состояния
- Нет сторис у подписок → лента сторис показывает только кнопку «Ваша история».
- Сторис истекла во время просмотра → переход к следующей.
- Исходный пост удалён → сторис удаляется вместе с ним (Q12).

## Зависимости
posts (сторис из поста), follows (лента), storage/media.

## Критерии приёмки
- [ ] Сторис недоступна через API после `expiresAt` (проверка фильтром в запросе, без фоновой задачи).
- [ ] Повторный просмотр не создаёт новую запись; автор свои просмотры не создаёт.
- [ ] Лента сторис группирует по автору; авторы с непросмотренными — первыми.
- [ ] Зрителей видит только автор; другим — `403`.
- [ ] Удаление сторис удаляет её файл (если это не пост).
- [ ] UI просмотра работает с клавиатуры (стрелки, Esc) и на мобильной ширине.
