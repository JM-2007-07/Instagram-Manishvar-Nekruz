# Подписки и связи

> Функции F-SOC-* · API [endpoints/follows.md](../api/endpoints/follows.md).

## Назначение
Подписки на открытые и закрытые аккаунты, запросы на подписку, списки, удаление подписчика, близкие друзья,
избранные аккаунты, рекомендации.

## Пользовательские сценарии
1. «Подписаться» на открытый → «Подписки ▾», счётчик +1. На закрытый → «Запрос отправлен» (повторное нажатие — отменить).
2. «Подписки ▾» → меню: «Добавить в близкие друзья», «Добавить в избранное», «Скрыть», «Ограничить», «Отменить подписку».
3. Владелец закрытого аккаунта: уведомления → «Запросы на подписку» → «Подтвердить» / «Удалить».
4. Списки «подписчики / подписки» — окно поверх профиля с поиском; у своих подписчиков — «Удалить».
5. Настройки → «Близкие друзья» — поиск и отметка галочкой; «Избранное» — до 50 аккаунтов.
6. «Рекомендации для вас» на главной и после подписки на профиле: «Подписаны: user1 и ещё 3» / «Популярное».

## Данные
`Follow` (`status`), `CloseFriend`, `FavoriteAccount` — [DATA_MODEL.md](../database/DATA_MODEL.md#подписки-follows).

## Права доступа
Подписка — от своего имени. Списки закрытого аккаунта — подписчикам. Близкие друзья и избранное — только владельцу
(участники списка о нём не знают, кроме зелёного кольца у историй).

## Валидация
Подписка на себя → `400`; на заблокированного / заблокировавшего → `404`; повторные `PUT`/`DELETE` — без ошибки.

## Ошибки и пустые состояния
«Нет подписчиков», «Вы ещё ни на кого не подписаны», «Нет запросов на подписку». Ошибка сети — кнопка возвращается
в прежнее состояние, тост.

## Зависимости
auth, users, privacy, notifications (`FOLLOW`, `FOLLOW_REQUEST`, `FOLLOW_ACCEPTED`). От follows зависят ленты, истории, рекомендации.

## Критерии приёмки
- [ ] Подписка на закрытый создаёт `PENDING` и уведомление владельцу; принятие → `ACCEPTED`, уведомление подписчику.
- [ ] Перевод аккаунта в открытый принимает все запросы.
- [ ] Удалённый подписчик не получает уведомления и теряет доступ к закрытому контенту.
- [ ] Блокировка удаляет подписки в обе стороны.
- [ ] Истории «для близких друзей» видят только участники списка.
- [ ] Списки пагинируются курсором и ищутся по имени.
