# Жалобы и администрирование

> Функции F-PRV-11, F-MOD-* · API [endpoints/admin.md](../api/endpoints/admin.md) · исходный Swagger #50 (удаление чужого аккаунта).

## Назначение
Жалобы пользователей на контент и аккаунты; панель администратора: очередь жалоб, удаление контента, баны, галочки,
справочник мест.

## Пользовательские сценарии
1. **Жалоба (P1):** «…» → «Пожаловаться» → причина (список) → при необходимости уточнение → «Спасибо, что сообщили».
2. **Очередь (P2):** `/admin/reports/` — фильтр по статусу и типу, предпросмотр объекта, действия «Отклонить»,
   «Удалить контент», «Заблокировать аккаунт».
3. **Галочка (P2):** найти пользователя → «Выдать / снять подтверждение».
4. **Бан:** аккаунт недоступен для входа, сессии завершены, профиль — «недоступна».

## Данные
`Report`, `User.status = BANNED`, `User.isVerified` — [DATA_MODEL.md «Модерация»](../database/DATA_MODEL.md#модерация-admin).

## Права доступа
Жалоба — любой вошедший (не на себя). Всё остальное — `ADMIN`; страница `/admin/…` проверяет роль в layout и на backend.

## Ошибки и пустые состояния
«Жалоб нет».

## Зависимости
auth (роль), все модули контента.

## Критерии приёмки
- [ ] Обычный пользователь получает `403` на всё под `/admin/`.
- [ ] Бан завершает все сессии и закрывает сокеты пользователя.
- [ ] Удаление контента по жалобе удаляет объект по правилам DATA_MODEL §4 и закрывает жалобу.
- [ ] Первый администратор создаётся seed-скриптом.
