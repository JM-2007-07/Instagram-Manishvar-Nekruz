# Приватность и безопасность

> Функции F-PRV-* · API [endpoints/privacy.md](../api/endpoints/privacy.md), настройки [endpoints/settings.md](../api/endpoints/settings.md),
> жалобы [endpoints/admin.md](../api/endpoints/admin.md) · правила видимости [SECURITY.md «Авторизация»](../architecture/SECURITY.md#авторизация).

## Назначение
Закрытый аккаунт, блокировка, ограничение, скрытие, «скрыть историю от», кто может комментировать/отмечать/упоминать,
сетевой статус, скрытие лайков, скрытые слова (P2), жалобы.

## Пользовательские сценарии
1. **Закрытый аккаунт:** настройки → «Конфиденциальность аккаунта» → переключатель; подтверждение при переключении.
2. **Заблокировать:** «…» на профиле, в чате или у комментария → подтверждение «Заблокировать @имя?» → профиль
   недоступен в обе стороны; список «Заблокированные» в настройках с «Разблокировать».
3. **Ограничить:** его новые комментарии видны только ему и мне («Одобрить» / «Удалить»), сообщения — в «Запросах»,
   он не видит, прочитал ли я и в сети ли я.
4. **Скрыть:** «Скрыть публикации» и/или «Скрыть истории» — без отписки и без уведомления.
5. **Скрыть историю от** — список в настройках историй.
6. **Комментарии / отметки / упоминания:** «Все / Ваши подписки / Ваши подписчики и подписки / Никто».
7. **Сетевой статус:** выключение скрывает и мой статус, и статусы других для меня.
8. **Скрыть число лайков:** у поста (при создании или потом) и глобально для чужих постов.
9. **Пожаловаться:** «…» → «Пожаловаться» → выбор причины → «Спасибо, что сообщили».

## Данные
`User.isPrivate`, `Block`, `Restrict`, `Mute`, `StoryHiddenFrom`, `HiddenWord`, `UserSettings`, `Report` —
[DATA_MODEL.md](../database/DATA_MODEL.md#приватность-privacy).

## Права доступа
Всё — только от своего имени. Правила видимости применяются **на backend во всех выдачах** (`VisibilityService`).

## Валидация
Нельзя применить к себе (`400`); повторные `PUT`/`DELETE` безопасны.

## Ошибки и пустые состояния
«Вы никого не заблокировали», «Вы никого не ограничили». Заблокированный видит «Пользователь не найден» и не знает о блокировке.

## Зависимости
users, follows, settings; используется всеми модулями выдачи (posts, comments, stories, chats, search, notifications, realtime, media).

## Критерии приёмки
- [ ] Блокировка: профиль, посты, истории, комментарии, лайки в списках, поиск, сообщения, звонки, события сокета
      недоступны в обе стороны; подписки удалены; e2e-тест по каждой выдаче.
- [ ] Закрытый аккаунт: неподписанный не получает публикации, reels, отметки, истории, списки подписок и файлы медиа
      (`GET /media/{id}` → 404).
- [ ] Ограничение: комментарий ограниченного создаётся с `isPendingApproval`; другие его не видят; одобрение показывает.
- [ ] Скрытие убирает посты/истории из лент скрывающего, но не из профиля.
- [ ] Настройка `commentsFrom = FOLLOWING` запрещает комментарии остальным (`403`).
- [ ] Выключенный сетевой статус не отправляет `presence:updated` и скрывает чужие статусы.
