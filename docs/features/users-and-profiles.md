# Профиль

> Функции F-PRF-* · API [endpoints/users.md](../api/endpoints/users.md) · экран [SCREENS.md §3.9](../design/SCREENS.md#39-профиль-) ·
> размеры [DESIGN_SYSTEM.md §4.3](../design/DESIGN_SYSTEM.md#43-профиль-).

## Назначение
Страница профиля `/{username}/` (своя и чужая, открытая и закрытая), редактирование профиля, аватар, ссылки.

## Пользовательские сценарии
1. **Чужой открытый профиль:** аватар 150 px (кольцо, если есть истории — клик открывает истории), имя пользователя,
   галочка, кнопки «Подписаться» / «Подписки ▾» / «Запрос отправлен», «Отправить сообщение», «…»; счётчики
   (публикации; подписчики и подписки — кликабельны); имя; bio с кликабельными `@` и `#`; ссылки («и ещё N»);
   «Подписаны: X, Y и ещё N»; актуальное; вкладки «Публикации / Reels / Отметки»; сетка 3:4.
2. **Закрытый профиль без подписки:** та же шапка и счётчики, вместо контента — замок и «Это закрытый аккаунт».
3. **Свой профиль:** «Редактировать профиль», «Посмотреть архив», настройки; вкладка «Сохранённое»; на плитках —
   закреплённые первыми со значком; «+ Новое» в актуальном.
4. **Редактировать профиль** (`/accounts/edit/`): фото («Загрузить фото», «Удалить текущее фото»), ссылки, о себе
   (счётчик 0/150), пол, местоимения, имя, имя пользователя; «Отправить».
5. **Наведение на плитку:** число лайков и комментариев поверх затемнения; клик — окно поста.
6. **Меню «…» на чужом профиле:** пожаловаться, заблокировать, ограничить, скрыть, «Об этом аккаунте» (P2),
   поделиться, скопировать ссылку.

## Данные
Поля профиля в `User`, `UserLink`, `MediaFile` (аватар) — [DATA_MODEL.md](../database/DATA_MODEL.md#профиль-users--поля-в-user).

## Права доступа
Шапка — всем вошедшим, кроме блокировки (→ 404). Контент закрытого аккаунта — подписчикам. Изменение — только `/me`.
`email` и дата рождения — только сам.

## Валидация 📝
| Поле | Правило |
|---|---|
| `bio` | ≤ 150 символов, переносы строк сохраняются |
| `fullName` | 1–64; лимит «не чаще 2 раз за 14 дней» **пока не реализован** — в модели данных нет учёта смен (T1.A3, Q-new-1) |
| ссылки | до 5, `https?://`, заголовок ≤ 30 |
| `pronouns` | свободная строка ≤ 50 (список значений не задан; T1.A3, Q-new-2) |
| аватар | изображение ≤ 10 МБ; обрезается в круг на клиенте |

## Ошибки и пустые состояния
- Нет пользователя / блокировка → «К сожалению, эта страница недоступна».
- Нет публикаций: свой — «Поделиться фото» + кнопка; чужой — «Публикаций пока нет».
- Нет отметок, reels, сохранённого — свои тексты 📝 по SCREENS.md.

## Зависимости
auth, media, follows (счётчики, `followStatus`), privacy (видимость), stories (кольцо, актуальное), posts (сетка).

## Критерии приёмки
- [ ] `/{username}/` открывает профиль без учёта регистра; несуществующее имя — экран «недоступна».
- [ ] Закрытый профиль без подписки показывает шапку, но `GET /users/{id}/posts` → `403 PRIVATE_ACCOUNT`.
- [ ] Числа ≥ 10 000 сокращаются («12,3 тыс.», «686 млн» ✅).
- [ ] Шапка, актуальное, вкладки, сетка совпадают с DESIGN_SYSTEM §4.3 в обеих темах.
- [ ] `PATCH /me` с лишним полем (`role`) → `400`.
- [ ] Новый аватар заменяет старый, старый файл удаляется.
- [ ] Ссылки, bio с `@`/`#` кликабельны; длинное bio не ломает раскладку.
