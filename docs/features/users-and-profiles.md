# Пользователи и профили

## Назначение
Профиль пользователя (свой и чужой), редактирование, аватар, поиск пользователей, удаление аккаунта.
Покрывает теги `User` (кроме истории поиска) и `UserProfile` исходного Swagger.

## Пользовательские сценарии
1. **Мой профиль:** аватар, `userName`, `fullName`, «о себе», счётчики постов/подписчиков/подписок, сетка постов, кнопка «Редактировать».
2. **Чужой профиль:** то же + кнопка «Подписаться/Вы подписаны» и «Написать» (создаёт/открывает чат).
3. **Редактирование:** «о себе», пол (Q9), `fullName` (Q8).
4. **Аватар:** загрузить/заменить, удалить → показывается заглушка.
5. **Поиск:** ввод строки → список пользователей (аватар, `userName`, `fullName`); выбор → профиль
   (и запись в историю поиска — [search-history.md](search-history.md)).
6. **Удаление аккаунта:** настройки → ввод пароля → подтверждение → выход, аккаунт удалён (Q7).

## API
`GET /me`, `PATCH /me`, `PUT /me/avatar`, `DELETE /me/avatar`, `DELETE /me`, `GET /users`, `GET /users/{userId}`,
(`GET /users/by-username/{userName}` — Q5) — [API_CONTRACT.md §2.2](../api/API_CONTRACT.md#22-me-и-профили-users-module).
Посты профиля — `GET /users/{userId}/posts` ([posts.md](posts.md)).

## Данные
`User` (поля профиля внутри), `MediaFile` для аватара. Счётчики вычисляются.

## Права доступа
- Профиль любого пользователя видит любой вошедший (приватных аккаунтов нет — Q22).
- `email` возвращается только в `GET /me`.
- Изменять можно только свой профиль (`/me`).
- Удаление чужих аккаунтов — только `ADMIN` (Q6), в объём по умолчанию не входит.

## Валидация 📝
| Поле | Правило |
|---|---|
| `about` | ≤ 150 символов, может быть пустым (`null`) |
| `gender` | значение enum или `null` (Q9) |
| `fullName` | 1–60 символов (если изменение разрешено — Q8) |
| аватар | JPEG/PNG/WebP, ≤ 5 МБ |
| `search` | 1–50 символов; поиск без учёта регистра по началу/вхождению в `userName` и `fullName` |
| `DELETE /me` | `password` обязателен и должен быть верным |

## Ошибки и пустые состояния
- Пользователь не найден → `404` → страница «Пользователь не найден».
- Нет постов → «Пока нет публикаций» (свой профиль — кнопка «Создать первый пост»).
- Поиск без результатов → «Ничего не найдено».
- Аватар не прошёл проверку → `413`/`415` → сообщение у поля загрузки.
- Неверный пароль при удалении → `400`, ошибка у поля.

## Зависимости
auth (сессия), storage/media (аватар), follows (счётчики и `isFollowedByMe`), posts (сетка постов).
`isFollowedByMe` и счётчики подписок появляются после влития follows — до этого `false`/`0`.

## Критерии приёмки
- [ ] `GET /users/{id}` возвращает профиль без `email`; `GET /me` — с `email`.
- [ ] `PATCH /me` с лишним полем (например, `role`) → `400`, роль не меняется.
- [ ] Загрузка аватара заменяет старый файл (старый удалён из хранилища).
- [ ] Поиск находит пользователя по части `userName` и `fullName`, без учёта регистра, постранично; по email — не находит.
- [ ] Удаление аккаунта удаляет данные по правилам Q7 и завершает все сессии.
- [ ] UI: профиль, редактирование, поиск работают на мобильной ширине; есть состояния загрузки/пусто/ошибка.
