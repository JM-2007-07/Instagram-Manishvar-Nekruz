# Места

> Функции F-PST-07, F-SRC-05, F-MOD-03 · API [endpoints/locations.md](../api/endpoints/locations.md) · исходный Swagger #16–#20.
> Q20 решён: места используются как в Instagram — у публикаций и историй, со страницей места.

## Назначение
Справочник мест (название, город, регион, индекс, страна, координаты), выбор места при публикации и в стикере
истории, страница места с публикациями, администрирование справочника.

## Пользовательские сценарии
1. При создании публикации — «Добавить место» → поиск по справочнику → место под именем автора в карточке ✅.
2. Клик по месту → `/explore/locations/{id}/{slug}/`: название, адрес, карта (статичная, P2), сетка «Лучшие» / «Недавние».
3. Стикер «Место» в истории → та же страница.
4. Администратор (`/admin/locations/`) — создать, изменить, удалить; seed наполняет справочник городами и популярными местами.

## Данные
`Location`, `Post.locationId`, стикер `LOCATION` — [DATA_MODEL.md «Места»](../database/DATA_MODEL.md#места-locations).

## Права доступа
Чтение — все вошедшие; изменение — `ADMIN`. Страница места показывает только видимые публикации.

## Валидация 📝
`name` 1–100, `city` и `country` обязательны, координаты в допустимых диапазонах.

## Ошибки и пустые состояния
«Ничего не найдено» при поиске; «Публикаций пока нет» на странице места.

## Зависимости
auth (роль), posts, stories, search, privacy.

## Критерии приёмки
- [ ] Поиск места при публикации находит по названию и городу.
- [ ] Удаление места снимает его у публикаций и стикеров, не ломая их.
- [ ] Изменяющие операции доступны только `ADMIN` (`403` остальным).
