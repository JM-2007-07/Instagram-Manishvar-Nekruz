# Настройки и меню «Ещё»

> Функции F-SET-*, F-PRV-06, 07, 09, 10, F-NTF-06 · API [endpoints/settings.md](../api/endpoints/settings.md) ·
> экран [SCREENS.md §3.14](../design/SCREENS.md#314-настройки).

## Назначение
Меню «Ещё», переключение темы, язык, разделы настроек: профиль, приватность, уведомления, близкие друзья,
заблокированные, комментарии и упоминания, истории, сетевой статус, пароль и сессии, удаление аккаунта, ваши действия (P2).

## Пользовательские сценарии
1. **«Ещё» (P0):** «Настройки», «Ваши действия» (P2), «Сохранённое», «Переключить режим», «Сообщить о проблеме»,
   «Переключение между аккаунтами» (P2), «Выйти».
2. **Переключить режим (P0):** светлая / тёмная / как в системе — мгновенно, без мигания при перезагрузке.
3. **Разделы (P0/P1):** `/accounts/settings/{section}/` — список разделов слева, содержимое справа; переключатели как в Instagram ✅.
4. **Язык (P1):** русский / английский; применяется ко всему интерфейсу.

## Данные
`UserSettings`, `NotificationPreference` — [DATA_MODEL.md «Настройки»](../database/DATA_MODEL.md#настройки-settings).

## Права доступа
Только владелец.

## Валидация
Значения перечислений из [endpoints/settings.md](../api/endpoints/settings.md).

## Ошибки и пустые состояния
Ошибка сохранения переключателя — возврат в прежнее положение + тост.

## Зависимости
auth (пароль, сессии), users (профиль), privacy, follows (близкие друзья), notifications.

## Критерии приёмки
- [ ] Тема сохраняется на сервере и в cookie; первая отрисовка — сразу в выбранной теме.
  Cookie ставит backend в ответе `PATCH /me/settings`, если в теле есть `theme`: имя `theme`, значения `light` | `dark` | `system`,
  не HttpOnly (читает frontend), SameSite=Lax, срок 1 год (T1.A3, Q-new-3). Язык — `ru` | `en`.
- [ ] Все настройки приватности из каталога доступны и влияют на выдачу (проверяется тестами privacy).
- [ ] Язык переключает все тексты интерфейса; даты и числа форматируются по языку.
