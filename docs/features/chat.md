# Direct — сообщения

> Функции F-DM-* · API [endpoints/chats.md](../api/endpoints/chats.md) · события [REALTIME.md](../api/REALTIME.md) ·
> экран [SCREENS.md §3.11](../design/SCREENS.md#311-direct) · правила [REQUIREMENTS.md §4.7](../REQUIREMENTS.md#47-сообщения).

## Назначение
Личные и групповые переписки в реальном времени: текст, фото и видео, голосовые, «поделиться», ответы на сообщения и
истории, реакции, редактирование, отмена отправки, «прочитано», «печатает», сетевой статус, запросы на переписку.

## Пользовательские сценарии
1. **Список (P0):** `/direct/inbox/` — чаты по последней активности; непрочитанные — жирным с точкой; вкладки
   «Основное» и «Запросы (N)»; «Новое сообщение» → поиск людей → один — личный чат, несколько — группа.
2. **Переписка (P0):** шапка (аватар, имя, «В сети» / «Был(а) в сети N мин назад», аудио, видео, «i»); пузыри
   ✅ с группировкой подряд идущих; время по разделителям; «Просмотрено» под последним своим.
3. **Отправка (P0):** текст (Enter — отправить, Shift+Enter — перенос), эмодзи, фото/видео (несколько),
   сердце одним нажатием; сообщение появляется сразу («отправляется»), затем подтверждается.
4. **Голосовое (P1):** удержание/нажатие микрофона → запись с таймером → отправить или отменить; плеер с волной и длительностью.
5. **Действия с сообщением (P1):** наведение → реакция, «Ответить», «…» (своё: «Изменить» 15 мин, «Отменить отправку»;
   любое: «Копировать», «Переслать», «Пожаловаться»); двойной клик — ❤️.
6. **Поделиться в Direct (P0):** публикация, reel, профиль, история — карточка с переходом.
7. **Ответ на историю (P0):** сообщение с миниатюрой истории («Ответил(а) на вашу историю»).
8. **Печатает… (P1)** — индикатор в переписке и в списке.
9. **Группа (P1):** «i» → название, фото, участники (добавить, удалить — администратор, назначить администратора),
   «Выйти из чата»; системные сообщения «user добавил(а) user2».
10. **Запросы (P1):** сообщение от неподписанного — во вкладке «Запросы»: «Принять», «Удалить», «Заблокировать».
11. **«i» → «Без звука», «Удалить чат»** (только у себя), «Заблокировать», «Пожаловаться».

## Данные
`Chat`, `ChatParticipant`, `Message`, `MessageMedia`, `MessageReaction` — [DATA_MODEL.md «Direct»](../database/DATA_MODEL.md#direct-chats).

## Права доступа
Всё — участникам (иначе `404`). Изменить и отменить — автор. Управление группой — администраторы (название и фото —
любой участник 📝). Блокировка запрещает переписку в обе стороны.

## Валидация 📝
Текст ≤ 1000 символов; до 10 медиа; голосовое ≤ 60 с; группа ≤ 250 участников, название ≤ 50; нельзя писать себе.

## Ошибки и пустые состояния
Нет переписок → «Ваши сообщения» + «Отправить сообщение». Пустой чат → профиль собеседника по центру
(«Посмотреть профиль»). Не отправилось → «Не отправлено» + «Повторить». Удалённый собеседник — «Пользователь ‹APP_NAME›».

## Зависимости
auth, users, media, privacy, realtime, follows (запросы), stories (ответы), posts (поделиться), calls.

## Критерии приёмки
- [ ] Сообщение доходит до открытой вкладки собеседника < 1 с без перезагрузки; во все вкладки отправителя.
- [ ] `POST /chats` с тем же собеседником возвращает существующий личный чат.
- [ ] Не-участник получает `404` на чат, сообщения, вложения и события.
- [ ] Отмена отправки убирает сообщение у всех (`message:unsent`); удаление чата скрывает его только у меня.
- [ ] Редактирование после 15 минут → `409`; отметка «Изменено».
- [ ] «Прочитано» и «печатает» обновляются в реальном времени и не показываются ограниченному пользователю.
- [ ] Сообщение от неподписанного попадает в «Запросы» получателя.
- [ ] Повторная отправка с тем же `clientId` не создаёт дубликат.
- [ ] Голосовое записывается в Chrome и Firefox, воспроизводится у собеседника.
- [ ] После переподключения сокета пропущенные сообщения появляются (сброс тегов).
