# Чат и сообщения

## Назначение
Личная переписка 1:1 с текстом и вложениями. Без real-time до ответа на Q19 — обновление через polling.

## Пользовательские сценарии
1. **Начать чат:** на профиле — «Написать» → открывается существующий чат или создаётся новый.
2. **Список чатов:** собеседник, последнее сообщение, время; сортировка по последней активности.
3. **Переписка:** сообщения снизу вверх, подгрузка старых при прокрутке вверх; новые появляются в течение ~5 с.
4. **Отправка:** текст и/или файл (Q17) → сообщение сразу появляется (после ответа сервера).
5. **Удаление сообщения:** своё → «Удалить» → исчезает у обоих (Q16).
6. **Удаление чата:** «Удалить чат» → подтверждение → исчезает у обоих (Q16).

## API
`GET /chats`, `POST /chats`, `GET /chats/{chatId}`, `DELETE /chats/{chatId}`, `GET|POST /chats/{chatId}/messages`,
`DELETE /chats/{chatId}/messages/{messageId}` — [API_CONTRACT.md §2.6](../api/API_CONTRACT.md#26-chats-chats-module).
Вложения отдаются через `GET /media/{mediaId}` только участникам.

## Данные
`Chat(user1Id, user2Id)` — пара упорядочена и уникальна; `Message` с `text?` и `attachmentMediaId?`.

## Права доступа
- Всё — только участникам чата; для остальных чат «не существует» (`404`).
- Удалить сообщение — только его автор.
- Писать самому себе нельзя (`400`).

## Валидация 📝
- Текст ≤ 2000 символов; хотя бы текст или файл.
- Файл — по Q17 (по умолчанию изображения/видео, ≤ 25 МБ).

## Ошибки и пустые состояния
- Нет чатов → «Напишите кому-нибудь» + ссылка на поиск.
- Пустой чат → «Начните переписку».
- Чат удалён собеседником → `404` → возврат к списку с сообщением.
- Ошибка отправки → сообщение остаётся в поле ввода, toast.

## Зависимости
auth, users, storage/media. Real-time — Socket.IO (+ Redis при нескольких экземплярах), только после Q19.

## Критерии приёмки
- [ ] `POST /chats` с тем же собеседником возвращает существующий чат (`200`), а не создаёт второй.
- [ ] Не-участник получает `404` на чат, сообщения и вложения.
- [ ] Сообщение без текста и файла → `400`.
- [ ] Удаление сообщения/чата соответствует Q16; файлы вложений удаляются.
- [ ] Список сообщений постраничный, новые сначала; клиент не показывает дублей при сдвиге страниц (Q29).
- [ ] Polling работает только на открытом экране чата.
