# Уведомления

> Функции F-NTF-* · API [endpoints/notifications.md](../api/endpoints/notifications.md) · события [REALTIME.md](../api/REALTIME.md) ·
> экран [SCREENS.md §3.13](../design/SCREENS.md#313-уведомления). Q21 решён: уведомления входят в объём.

## Назначение
Панель «Уведомления» с группировкой, значки в меню, доставка в реальном времени, настройки по типам.

## Пользовательские сценарии
1. **Значки (P0):** точка на «Уведомления» ✅ при новых; красный счётчик на «Сообщения» ✅ («9+»).
2. **Панель (P0):** сверху «Запросы на подписку» (если закрытый аккаунт); затем группы «Новые / Сегодня / На этой
   неделе / В этом месяце / Ранее»; строка: аватар(ы) — текст с жирными именами — время — миниатюра поста или
   кнопка «Подписаться» / «Подписки».
3. **Группировка (P1):** «user1, user2 и ещё 5 нравится ваша публикация».
4. **Открытие панели** отмечает уведомления прочитанными, точка исчезает.
5. **Настройки (P1):** включить/выключить по типам (лайки, комментарии, подписки, упоминания, отметки, истории).

## Типы
`POST_LIKE`, `COMMENT_LIKE`, `COMMENT`, `COMMENT_REPLY`, `MENTION_POST`, `MENTION_COMMENT`, `MENTION_STORY`, `POST_TAG`,
`FOLLOW`, `FOLLOW_REQUEST`, `FOLLOW_ACCEPTED`, `COLLAB_INVITE`.

## Данные
`Notification`, `NotificationPreference` — [DATA_MODEL.md «Уведомления»](../database/DATA_MODEL.md#уведомления-notifications).

## Права доступа
Только получатель. Создание — модулями-источниками через `NotificationsService` с учётом настроек, блокировок,
ограничений; себе — никогда.

## Ошибки и пустые состояния
«Действия с вашими публикациями» + пояснение 📝.

## Зависимости
posts, comments, follows, stories, tags, settings, privacy, realtime.

## Критерии приёмки
- [ ] Каждое действие из «Типов» создаёт уведомление получателю и событие `notification:new` < 1 с.
- [ ] Отменённое действие (снятый лайк, отписка) удаляет непрочитанное уведомление.
- [ ] Группировка объединяет одинаковые действия с одним объектом за 24 часа: лайки поста — по посту, лайки
  комментария — по комментарию. Комментарии, ответы, упоминания и отметки не объединяются (у каждого свой текст).
- [ ] Выключенный тип не создаёт уведомлений; блокировка и ограничение — тоже.
- [ ] Значки совпадают с `GET /me/badges` после перезагрузки.

## Открытые вопросы
