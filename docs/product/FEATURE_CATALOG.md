# Каталог функций (паритет с веб-Instagram)

> Статус: ✅ принят принцип «как в настоящем Instagram» ([ADR 0011](../decisions/0011-instagram-parity-scope.md)).
> Это **продуктовый источник истины**: что умеет приложение и как ведёт себя каждая функция.
> Требования ([REQUIREMENTS.md](../REQUIREMENTS.md)), контракт ([api/](../api/API_CONTRACT.md)), модель данных и спецификации
> функций ссылаются на ID отсюда (`F-PST-07`).

## Как читать

| Колонка | Смысл |
|---|---|
| **ID** | `F-<область>-<номер>`; используется в спецификациях, контракте, задачах |
| **Как в Instagram** | наблюдаемое поведение. ✅ — проверено на instagram.com 2026-10-21; без отметки — по описанию продукта, проверить при реализации; 📝 — точное число/лимит не подтверждён |
| **Приоритет** | **порядок реализации, а не исключение**: P0 — ядро (первым), P1 — полный паритет, P2 — сложные дополнения. Всё в каталоге входит в объём проекта |
| **Модуль** | модуль backend (`apps/api/src/<module>`) |

Исключено только то, что невозможно или не имеет смысла без инфраструктуры Meta — раздел [«Вне объёма»](#вне-объёма).
