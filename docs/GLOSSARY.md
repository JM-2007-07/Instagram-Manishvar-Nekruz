## Предметная область

| Термин | Значение |
|---|---|
| **Пост (публикация)** | 1–20 фото и видео (карусель) + подпись; адрес `/p/{shortcode}/` |
| **Reel** | публикация с одним вертикальным видео (`type = REEL`), адрес `/reel/{shortcode}/` |
| **Лента (feed)** | посты подписок и мои, новые сначала с подъёмом «Избранного» — `GET /feed`; «Подписки» и «Избранное» — строго по времени |
| **«Интересное» (explore)** | посты и reels открытых аккаунтов, на которые я не подписан, по взаимодействиям за 7 дней — `GET /explore` |
| **История (story)** | публикация на 24 часа: фото/видео или карточка поста, со стикерами; затем — в архив |
| **Подписка (follow)** | `follower` подписан на `following`; подписчики = followers, подписки = following |
| **Сохранённое (saved)** | личный список сохранённых постов и подборки (исходный «favorites» Swagger) |
| **Избранное (favorite accounts)** | до 50 аккаунтов, чьи посты выше в ленте |
| **Просмотр (play / view)** | воспроизведение видео (не чаще раза в час на пользователя) и просмотр истории |
| **Чат** | личная (2 участника) или групповая переписка в Direct |
| **История поиска** | недавние запросы, аккаунты, хэштеги и места из поиска (`/me/search-history`) |
| **Место (location)** | запись справочника: название, город, регион, индекс, страна; у публикаций и историй |

## Технические термины

| Термин | Значение в проекте |
|---|---|
| **Сессия** | запись `Session` в PostgreSQL; браузер хранит только случайный токен в HttpOnly cookie |
| **HttpOnly cookie** | cookie, недоступная JavaScript; защищает токен от кражи через XSS |
| **CSRF** | подделка запроса с чужого сайта; защита — `SameSite=Lax` + проверка `Origin` |
| **Same-origin прокси** | правило `rewrites` в Next.js: браузер обращается к `/api/v1/...` на адресе сайта, Next.js пересылает в NestJS |
| **Контракт** | описание API: `API_CONTRACT.md` + `api/endpoints/*.md` + `REALTIME.md` → после Phase 0 — Swagger NestJS (`docs/api/openapi.json`) |
| **`npm run contract`** | экспорт Swagger из NestJS + генерация типов frontend (`schema.d.ts`) |
| **DTO** | класс NestJS, описывающий и проверяющий тело/параметры запроса или ответ |
| **Guard** | класс NestJS, решающий, пропускать ли запрос (у нас — `SessionGuard`) |
| **Server / Client Component** | компонент Next.js, выполняемый на сервере / в браузере (`'use client'`) |
| **Инвалидация (теги)** | мутация RTK Query «сбрасывает» теги (`invalidatesTags`), и все запросы с этими тегами (`providesTags`) загружаются заново |
| **RTK Query** | часть Redux Toolkit для запросов: эндпоинты описываются в `api.ts`, хуки (`useGetPostQuery`) создаются автоматически, кэш управляется тегами |
| **Миграция** | SQL-файл Prisma, переводящий БД из одной версии схемы в другую |
| **Seed** | скрипт с тестовыми данными для локальной БД |
| **ADR** | короткая запись архитектурного решения: контекст, решение, альтернативы, последствия |
| **История (story)** | файл `docs/stories/ГГГГ-ММ-ДД_ЧЧММ_<slug>.md` о значимом действии: запрос, что сделано, почему, файлы, проверки, проблемы, что дальше; только добавляется |
| **Shortcode** | 11-символьный код публикации в адресе `/p/{shortcode}/` (как в Instagram) |
| **VisibilityService** | сервис модуля `privacy`: единая проверка «может ли пользователь видеть объект» (блокировки, закрытые аккаунты, аудитория историй) |
| **Курсор** | непрозрачная строка для следующей страницы списка (`nextCursor`, ADR 0017) |
| **Близкие друзья** | личный список; истории для них — с зелёным кольцом |
| **Ограничение (restrict)** | комментарии пользователя видны только ему, пока не одобрены; сообщения — в запросах |
| **Актуальное (highlights)** | подборки историй на профиле, не исчезают через 24 часа |
| **Дизайн-сверка** | сравнение нашего экрана с Instagram по скриншотам и вычисленным стилям (SCREENS.md §0) |
| **Harness** | всё, что помогает агенту работать надёжно: AGENTS.md, карта документов, STATUS, сценарии, проверки в CI |
| **Socket.IO** | канал реального времени: сообщения, «печатает», присутствие, уведомления, сигналы звонков (ADR 0013) |
| **WebRTC** | звонки: звук и видео напрямую между браузерами (ADR 0015) |
