# infrastructure/docker

> **Статус:** пусто намеренно. Docker на машинах разработчиков пока не установлен,
> а PostgreSQL установлен локально — для начала разработки Docker не нужен.

Здесь появится `docker-compose.yml`, когда для него будет конкретная причина:

| Сервис | Когда добавить |
|---|---|
| PostgreSQL | если версии/настройки локальных установок начнут расходиться |
| MinIO (локальный S3) | при проверке драйвера `s3` для медиа без облачного аккаунта |
| Mailpit | при проверке отправки писем сброса пароля |
| Redis | когда будет одобрен Redis (см. ARCHITECTURE.md, раздел «Будущая инфраструктура») |

Dockerfile'ы приложений — на этапе деплоя (Phase 6), когда будет выбрана среда развёртывания.
