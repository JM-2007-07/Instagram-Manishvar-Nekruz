# CLAUDE.md — инструкции для Claude Code

Общие правила для всех ИИ-агентов находятся в AGENTS.md и подключаются ниже. Этот файл добавляет
только то, что относится к Claude Code. Правила не дублируются: меняйте их в AGENTS.md.

@AGENTS.md

## Дополнительно для Claude Code

- В начале сессии прочитай [docs/STATUS.md](docs/STATUS.md) — даже если задача кажется понятной.
- Для задач больше 2–3 файлов веди список шагов и сначала покажи план пользователю.
- Перед изменением общего файла, `schema.prisma` или API-контракта — спроси подтверждение пользователя.
- В конце задачи: обнови STATUS.md (через `docs-keeper`), сделай коммит в текущей ветке и кратко сообщи, что не проверено.
- Пользователи общаются на русском — отвечай на русском.

## Субагенты (ты — оркестратор)

В `.claude/agents/` есть 8 агентов. Роли, модели и конвейер — [docs/development/AI_AGENTS.md](docs/development/AI_AGENTS.md).

| Нужно | Агент |
|---|---|
| спланировать задачу `Tx.y` | `planner` (Opus) |
| изменить API-контракт или схему БД | `contract-designer` (Opus), только после согласия пользователя |
| код в `apps/api` | `backend-dev` (Sonnet) |
| код в `apps/web` | `frontend-dev` (Sonnet) |
| тесты | `test-writer` (Sonnet) |
| запустить lint/typecheck/test | `verifier` (Haiku) |
| ревью перед коммитом | `reviewer` (Opus) |
| обновить STATUS.md, закрыть `Qn`, проверить ссылки | `docs-keeper` (Haiku) |

Правила оркестратора:

1. Только ты общаешься с пользователем и получаешь подтверждения; агентам передавай уже принятые решения.
2. Агент стартует без контекста разговора: в задании всегда ID задачи, модуль, владелец, шаг плана и нужные
   результаты предыдущих агентов (выжимку, см. AI_AGENTS.md §5).
3. Независимые шаги (например, `frontend-dev` и `test-writer` после `npm run contract`) запускай параллельно.
4. Мелкие задачи (1–2 файла, без прав доступа и общих файлов) делай сам, без конвейера — агенты стоят времени.
5. Не пересказывай пользователю отчёты агентов целиком: итог, что не проверено, что требует решения.
6. Коммиты делаешь только ты, после зелёного `verifier` и без 🔴 от `reviewer`.
