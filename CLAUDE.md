## Дополнительно для Claude Code

- В начале сессии прочитай [docs/STATUS.md](docs/STATUS.md) — даже если задача кажется понятной.
- Для задач больше 2–3 файлов веди список шагов и сначала покажи план пользователю.
- Для широкого поиска по коду используй субагентов только с явного разрешения пользователя;
  обычно достаточно Grep/Glob.
- Перед изменением общего файла, `schema.prisma` или API-контракта — спроси подтверждение пользователя.
- В конце задачи: обнови STATUS.md (статус задачи и строка в журнале) и кратко сообщи, что не проверено.
- Пользователи общаются на русском — отвечай на русском.
